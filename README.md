# GL Portfolio — Deifer Garanton

Portfolio profesional de **Deifer Garanton** — Ingeniero, Arquitecto de Sistemas y Desarrollador Full-Stack.

Catalogo completo de logros, proyectos y beneficios de mas de 40 repositorios distribuidos en 4 nodos operativos: **MINPI**, **Sunai**, **Pablo** y **Genio Loco**.

---

## Stack

| Tecnologia | Version |
|------------|---------|
| **Laravel** | 13.x |
| **Livewire** | 4.x |
| **Flux UI** | 2.x |
| **Tailwind CSS** | 4.x |
| **Laravel Fortify** | 1.x |
| **PHP** | 8.3 |
| **Vite** | 8.x |

---

## Caracteristicas

- Diseno oscuro profesional con acentos en azul y violeta
- Secciones por nodo operativo (MINPI, Sunai, Pablo, GL)
- Iconos de tecnologia integrados via Devicon CDN
- Animaciones suaves con AOS (Animate On Scroll)
- Cards tipo glow con hover effects
- Totalmente responsive
- Built con Laravel Starter Kit (Livewire + Flux)

## Instalacion

```bash
git clone https://github.com/deiferd3g/gl_portfolio.git
cd gl_portfolio
composer install
npm install
cp .env.example .env
php artisan key:generate
npm run build
php artisan serve
```

## Despliegue

Compatibilidad total con Docker a traves del ecosistema Vegapunk:

```bash
# Desde el directorio docker/
./create-project.sh gl_portfolio 8085
```
